## What the app does

Trader_7_12 Pro is a read-only market-information application. It retrieves market data from external data providers and presents analytical information in the application.

## Information stored locally

The application may store an authentication refresh token required to access the configured BCS data service.

The token is used only to authenticate requests to the configured data provider. It is not used for advertising or user profiling.

For the Mac App Store release, the token must be stored inside the application's App Sandbox container. It must not be stored in an unrestricted path in the user's home directory.

## Information transmitted to third parties

The application sends requests to the configured market-data services required to retrieve market information.

Current integrations include:
- BCS market-data services.
- Moscow Exchange market-data services where used by the application.

The application does not transmit market-data credentials to advertising networks or analytics providers.

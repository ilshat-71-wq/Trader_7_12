## 1. КАНОНИЧЕСКАЯ ТОРГОВАЯ ЛОГИКА

Пользователь торгует **фьючерс**, но идея и структура движения определяются по **SPOT / базовому активу**.

Жёсткое правило:

`SPOT → SPOT STRUCTURE → FUTURES CONFIRMATION → USER ENTRY`

Фьючерс — практический инструмент для сделки. SPOT — источник направления и структуры.

Пользователь самостоятельно контролирует точку входа. Приложение не выдаёт автоматическую команду на вход.

## 2. ПЕРВЫЙ ОТКАТ / ПЕРВЫЙ ОТСКОК

Для LONG:

`SPOT импульс вверх → первый откат вниз → зона консолидации → сила сохраняется → соответствующий FUTURES`

Для SHORT:

`SPOT импульс вниз → первый отскок вверх → зона консолидации → слабость сохраняется → соответствующий FUTURES`

Рабочий ориентир пользователя: откат примерно на **50% импульса** или к ближайшему значимому структурному уровню.

Приложение использует это как **фильтр качества кандидата**, а не как автоматическую точку входа.

## 3. ЧТО ИЩЕМ

Главный практический вопрос сканера:

> В каком SPOT сегодня есть деньги, движение и качественная структура, чтобы соответствующий фьючерс был интересен для самостоятельной сделки?

Приоритет:

1. текущая активность и money volume SPOT;
2. импульс и структура SPOT;
3. первый pullback / rebound и консолидация;
4. относительная сила/слабость;
5. подтверждение и ликвидность FUTURES;
6. итоговый ranking TOP 2–3.

Фьючерс с большим оборотом не должен вытеснять более качественного SPOT-лидера.

## 4. СЕССИИ

Все времена — `Europe/Moscow`.

- `06:50–07:00` PRE_OPEN;
- `07:00–10:00` MORNING;
- `10:00–19:00` MAIN;
- `19:00–23:50` EVENING;
- `23:50–06:50` CLOSED.

UI всегда показывает живые дату и время МСК и текущую сессию. Отдельный countdown до конца сессии **не нужен**.

## 5. АКТУАЛЬНЫЙ UI

Зафиксирован согласованный дизайн:

- профессиональный спокойный тёмный интерфейс;
- компактная верхняя часть;
- одна кнопка сканирования;
- во время сканирования кнопка получает мягкую зелёно-салатовую пульсацию;
- в большом поле результатов во время сканирования показывается оригинальная анимированная сюрреалистическая композиция с плавящимися часами, вдохновлённая эстетикой Дали;
- после завершения сканирования анимация полностью исчезает и появляется результат;
- LONG отображается приятным мягким зелёным;
- SHORT отображается приятным мягким красным;
- двойные строки «идёт сканирование» не используются;
- верхние поля не заменяются анимацией.

## 7. ЖЁСТКИЕ ОГРАНИЧЕНИЯ

Не добавлять:

- автоматическое исполнение ордеров;
- автоматические точки входа;
- position sizing;
- автоматический SL/TP;
- portfolio management;
- risk management как часть scanner pipeline.

Historical replay остаётся read-only.

## 8. ТЕХНИЧЕСКАЯ ПАМЯТКА

`QPainter` импортируется из `PySide6.QtGui`, не из `PySide6.QtCore`.

Канонический принцип проекта:

**Сканер находит ГДЕ смотреть. Пользователь решает ГДЕ входить.**

**SPOT определяет идею и структуру. FUTURES — то, чем пользователь торгует.**
